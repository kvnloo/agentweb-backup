Bundled CJK fonts
------------------

Add at least one CJK font file here so PDF exports can render Chinese characters correctly. Recommended:

- NotoSansSC-Regular.otf (or .ttf)
- NotoSerifSC-Regular.otf (or .ttf)
- SourceHanSansSC-Regular.otf (or .ttf)
- SourceHanSerifSC-Regular.otf (or .ttf)

The backend automatically loads all .otf/.ttf files in this folder and exposes them to the export flow and font dropdown. Just add the font files here and restart the backend server.
