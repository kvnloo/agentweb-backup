# AgentWeb Customer Portal

This is the customer-specific frontend for AgentWeb, built to provide a dedicated portal for users with the 'customer' role.

## Features

- 🔒 Secure customer authentication
- 📊 Customer dashboard with template access
- 📝 Market research reports and materials
- ⚙️ Account settings and profile management

## Development

### Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The development server will start on port 5174 by default. You can access it at http://localhost:5174.

## Structure

This frontend uses the same codebase structure as the agent frontend but has been customized specifically for the customer role, with access limited to reports and resources rather than agent features.
