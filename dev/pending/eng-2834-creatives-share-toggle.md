## ENG-2834: per-org `creatives` share toggle on the workspace creative library (2026-11-15)

`creatives` is now a toggleable, member-owned org share feature (default on). The ENG-2874 workspace library (`/api/tasks/executions/with-images|with-videos|with-html-reports`) calls `scopeCallerToCreativesSharing` before fanning out: toggle off, org row missing, or org lookup failing all narrow the caller to their own assets. There is no owner/admin override, matching skills and work plans. Orgs that never saved the key read as on, so nothing changes until an org turns it off. PATCH share-settings back-fills the key from the stored value for portals that do not send it, so an older portal cannot re-enable a toggle the org turned off. Excluded from member-removal ownership cleanup. No migration or backfill. The portal settings toggle and owner/admin delete of a teammate's asset are not built.
