# Cycle 212 — do not 503 GET `/mcp`; 405 is the SDK skip

**Date:** 2026-09-12T04:05:00Z
**Question:** Cycle 211 left GET `/mcp`
SSE ungated (`mcpServer.ts` L508–531,
`setTimeout(0)`). Should A-019 HTTP 503
**new** GET the way it 503s POST
`tools/call`?

**Answer:** **No 503 on GET.** The
vendored Streamable HTTP client throws
on GET 503 and only treats **405** as
“no notification stream, keep POST.”
GET is not the billed-image gate. Q-001’s
Hermes fixture never GET. Existing SSE
still needs `mcpShutdown` after the wait
(cycle 72) — refusing new GET does not
close streams already open.
